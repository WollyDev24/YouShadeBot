    Commands

    Auto-join roles

    New members instantly get a role — a different one for real people and bots.

    Auto-update

    Every hour the bot checks GitHub for new commits. If there are any it pulls them, installs dependencies if needed and restarts itself. Updates are announced in the logging channel below.

    Auto-responses

    When a message matches a trigger, the bot replies automatically. Placeholders: {user} {username} {server}. Also available in Discord via /filter. 15s cooldown per rule and channel.

    Rules

    Starboard

    When a message collects enough reactions, it gets reposted to the starboard channel. Self-reactions and bots don't count; the board updates live as reactions come and go.

    Counting Game Emojis

    Customize the emojis the bot reacts with during the counting game. Set up the counting channel first with /counting setup.
