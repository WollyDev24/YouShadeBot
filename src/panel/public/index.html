    Auto-update

    Every hour the bot checks GitHub for new commits. If there are any it pulls them, installs dependencies if needed and restarts itself. Updates are announced in the logging channel below.

    Leveling

    Members earn XP by chatting and level up on an XP curve. Rewards and the announcement channel are configured here (or with /level).
